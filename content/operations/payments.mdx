Реестр всех регулярных платежей за инструменты и сервисы BBM: **что** мы
оплачиваем, **как** деньги доходят до сервиса и **когда** платим. Цель —
однозначность: заводя оплату, видно маршрут и каденс, без «запасов» на личном
счёте (их сложно отслеживать).

Карта самих сервисов/инфры — канонический [реестр экосистемы](/ecosystem)
(`ssot/services.yaml`); эта страница — только финансовая сторона.

## Схемы оплаты

У платежей три разных маршрута денег — это главная ось реестра.

| Схема | Маршрут | Для чего |
|---|---|---|
| **A. Карта Антона + компенсация** | Аня заводит в `konsol.pro` задание в сторону Антона на сумму в ₽ → юрлицо оплачивает задание → Антон получает деньги → платит сервису личной иностранной картой | все зарубежные сервисы (AI, медиа, связь) |
| **B. Прямой счёт юрлица** | Сервис выставляет счёт на ООО → бухгалтер оплачивает с расчётного счёта | российские сервисы по безналу (инфра) |
| **C. Разовая СБП / QR** | Российский сервис без счёта — оплата картой/СБП по QR | pay-as-you-go пополнения |

**Правило схемы A** (зафиксировано в канале 09.07): для **всех** зарубежных
сервисов — отдельное `konsol.pro`-задание на каждый платёж, не общим «депозитом».

## Оптимизация каденса (месяц / квартал / год)

По ресёрчу тарифов 2026-07-14. Общий принцип: **где кредиты сгорают в конце
месяца — предоплата на год/квартал бессмысленна** (замораживает деньги без
выгоды); **где подписка со скидкой за период и без потери гибкости — берём
длинный цикл**.

| Сервис | Длинный цикл | Скидка | Решение | Почему |
|---|---|---|---|---|
| Claude Max 20× | нет годовой | — | **месяц** | Max только помесячно |
| ChatGPT Pro | нет годовой | — | **месяц** | годовой оплаты не существует; отменять в простой |
| z.ai (GLM) | квартал −20%, год −30% | до −30% | **месяц (тест)** | сначала подтверждаем полезность, каденс — по факту |
| Higgsfield | год −23% (Ultra) | −23% | **месяц + top-up** | кредиты не переносятся; год окупается лишь при ≥9–10 мес/год продакшна |
| ElevenLabs | год −17% + rollover 2 мес | −17% | **год** (при стабильном юзе) | почти безрисково — кредиты переносятся |
| Zoom | год $169.9 | −17% | **год** | звонки регулярны |
| Timeweb | — | — | **месяц, счёт** | инфра, потребление растёт |

### Важные нюансы

- **z.ai под Hermes — легитимно.** GLM Coding Plan официально поддерживает
  сторонние/кастомные клиенты ([`docs.z.ai/devpack/tool/others`](https://docs.z.ai/devpack/tool/others)),
  подключение к Claude Code — через `ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic`.
  Сетка скидок по циклам: −10 % месяц / −20 % квартал / −30 % год. Стартуем с
  месяца, на квартал/год переходим после подтверждения пользы.
- **Claude Console как «запас» — сначала не отдельный ключ.** У Max есть
  встроенный overflow: usage-bundles ($50 −10 % / $250 −20 % / $1000 −30 %),
  включаются автоматически после исчерпания лимита плана — это и есть «продолжить
  работу при исчерпании лимитов». Отдельный Console API-ключ нужен только под
  программный доступ (Hermes / CI); класть немного + auto-reload, т.к. **купленные
  кредиты сгорают через 1 год** и невозвратны.
- **Claude Team-план невыгоден** малой команде: лимиты не пуловые (per-seat),
  минимум 5 мест. Дешевле индивидуальные Pro/Max, чем Team ради 2–3 человек.
- **Max 20× даёт ×4 к Max 5×** (не ×5): оба множителя считаются от базы Pro.

## Правила и гочи

- **Никаких «запасов» на личном счёте.** Каждый зарубежный платёж — отдельное
  `konsol.pro`-задание под конкретный сервис; «депозиты впрок» путают личные и
  корпоративные расходы и не отслеживаются.
- **Политика открытости.** Любой запрос средств — в канале «BBM Финансы», чтобы
  вся команда видела расходы (и выплаты друг другу).
- **Сгорающие кредиты ≠ предоплата.** Higgsfield / Claude API / кредитные
  подписки не «банкуют» неиспользованное — переход на год оправдан только при
  почти непрерывном использовании.
- **Долг по Zoom.** Сумма прошлой годовой подписки Zoom осела на личном счёте
  Антона как долг в сторону BBM — закрыть при активации годовой оплаты.
