## Глобальный ICOM-словарь

В IDEF0 каждая функция имеет четыре типа связей: **I** (Input) — входные
объекты, трансформируемые функцией; **C** (Control) — управляющие ограничения;
**O** (Output) — результаты; **M** (Mechanism) — ресурсы, выполняющие функцию.

### Глобальные управления (Controls)

| Объект | Описание | Область действия |
|--------|----------|-----------------|
| Принципы бирюзовых организаций, миссия, эв. цель | Ценностная основа: самоуправление, целостность, эволюционная цель (канон — [Миссия](/company/mission)) | Все функции A0 |
| White paper, инструкции | Операционные регламенты и описания продукта | A2–A7 |
| Финплан | Финансовый план, бюджетирование | A2, A3, A4 |
| Реестр команд | Доступные специалисты и их роли | A3, A4 |
| Комплайенс | Нормативные требования фарм-рынка | A3, A7 |
| Соглашение (контракт) с партнёрами | Юридически обязывающий документ партнёрства | A3, A5 |
| Система управления организацией | IT-инфраструктура управления (от A5) | A6 |

### Глобальные входы (Inputs)

| Объект | Описание |
|--------|----------|
| Ресурсы | Финансовые, человеческие и материальные ресурсы холдинга |
| Заявки от врачей | Входящий спрос от аудитории врачей |
| Распределённый доход | Рефид: доход, распределённый A6 обратно в проекты и партнёрскую функцию |

### Глобальные выходы (Outputs)

| Объект | Назначение |
|--------|------------|
| Прибыль | Финансовый результат экосистемы BBM |
| Комплайенс | Подтверждение соответствия нормативам фарм-рынка |
| Маркетинговые материалы | Контентные артефакты для продвижения проектов |
| Артефакты маркетинга | Выход функции A7 (маркетинг BBM как бренда) |

### Механизмы (Mechanisms — организационные круги)

Каждая функция A0 обслуживается отдельным самоуправляемым кругом ([[Circle]]):

| Круг | Функция |
|------|---------|
| Команда | Все функции (глобальный механизм) |
| Управленческий круг | A1 |
| HR круг | A2 |
| Командный круг | A3 |
| Партнёрский круг | A4 |
| IT круг | A5 |
| Финансовый круг | A6 |
| Маркетинговый круг | A7 |

## A0 — Контекстная диаграмма (TOP)

![A0 — контекстная диаграмма](/models/idef0/01_A0.png)

Самый верхний уровень: одна функция представляет всю систему BBM во внешнем
окружении («чёрный ящик»). BBM принимает ресурсы (капитал, люди, знания),
действует в рамках принципов бирюзовой организации и эволюционной цели и
производит прибыль силами команды.

| Тип | Объект |
|-----|--------|
| **I** | Ресурсы |
| **C** | Принципы бирюзовых организаций, миссия, эв. цель |
| **O** | Прибыль |
| **M** | Команда |

## Ключевые наблюдения

- **Рефид «Распределённый доход»:** A6 возвращает доход обратно в A3 и A4 —
  деньги поступают в проекты через финансовый круг, а не через внешнее
  финансирование.
- **«Соглашение с партнёрами»** — критическая стрелка: создаётся в A4, но
  разблокирует A3 (запуск проектов) и A5 (IT-обеспечение).
- **Бирюзовая структура в механизмах:** каждая функция A0 обслуживается
  отдельным самоуправляемым кругом — прямое отражение принципов Лалу.
- **Глубина модели:** 4 уровня декомпозиции (TOP → A0 → A3 → A31/A32/A4 → A323).
- **Приоритет расширения:** A1, A2, A5, A6, A7 — следующие кандидаты на
  декомпозицию.
